# Releases

每个 Cedar Render Foundation 发行版本单独一个目录。

```
releases/
├── README.md
└── v0.01/
    └── README.md
```

每个版本目录至少记录：

- Cedar release version
- package filename
- base CEF version
- Chromium version
- platform / architecture
- custom capabilities
- artifact SHA-256
- 来源 / build 信息
- compatibility notes
